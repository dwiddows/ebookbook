# ebookbook

LaTex e-book editable template that also typesets to the book about writing the book.

This is the TeX source for the book *LaTeX to eBook 2026: The Book About Itself*.
The first edition, [LaTeX to eBook 2021](https://www.amazon.com/-/dp/B09FKM3ZMH/), is in the Kindle Store.

Run `./build.sh` to build the PDF and the epub. Everything the build makes goes in the `build/` folder.

If you want to write an eBook using LaTeX, feel free to use this as a template and adapt it to your own book.
